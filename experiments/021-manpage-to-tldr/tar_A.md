# tar

> GNU Tar is an archiving program for storing and manipulating a collection of files in a single file.

> More information: <https://www.gnu.org/software/tar/manual>

- `tar -c -v -f etc.tar /etc`
- `tar -cf etc.tar /etc`
- `tar --create --file etc.tar /etc`
- `tar -d -f etc.tar /etc`
- `tar -df etc.tar /etc`
- `tar --diff --file etc.tar /etc`
- `tar -v --file etc.tar /etc`
